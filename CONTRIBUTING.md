# Contributing

Thanks for wanting to contribute to the project!
There are no complicated rules here. If you have an idea, improvement, bug fix, or UI/UX suggestion, feel free to contribute.

## Bug Fixes / Small Changes

If the change is small, you can directly:

1. Fork the repository
2. Create a new branch
3. Make your changes
4. Open a Pull Request

Please briefly explain what you changed and why.

## UI / UX Changes

For bigger UI/UX changes, please open an **Issue first**.

Share:

- What you want to improve
- Why you think it should be changed
- Screenshots, mockups, or a Figma link if you have one

This lets us discuss the idea before you spend time implementing it.

Once the idea is agreed on, feel free to open a Pull Request.

## Pull Requests

When opening a PR, please include:

- What you changed
- Why you changed it
- Screenshots for visual/UI changes

Keep PRs focused when possible. Smaller PRs are easier to review.

## Have an Idea?

Don't worry about getting everything perfect.

If you're not sure whether something is worth contributing, **open an Issue and let's discuss it.**

That's it. Have fun building!
